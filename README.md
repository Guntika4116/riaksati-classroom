# เรียกสติ — ห้องทดลอง AI สำหรับผู้ใหญ่ไม่เกิน 10 คน

เวอร์ชันนี้อยู่ใน `classroom/` แยกจากต้นฉบับที่ซิงก์มา ใช้ HTML/CSS/JavaScript เดิมและ Node.js API เชื่อม Google Gemini ไม่มีฐานข้อมูลและไม่มีค่าแพ็กเกจรายเดือนในตัวแอป

**สถานะ:** ทดสอบเรียก Gemini 3.5 Flash-Lite จริงผ่านแล้วเมื่อ 6 ต.ค. 2026 ทั้งแชต สรุป และสร้างแผน ด้วยเรื่องสมมติ การทดสอบอัตโนมัติ 10 กรณีผ่านแล้ว ยังไม่ได้เผยแพร่เว็บหรือทดสอบภาพในเบราว์เซอร์ คีย์จริงอยู่เฉพาะไฟล์ `.env` บนเครื่อง ไม่รวมใน ZIP

## สิ่งที่ทำได้

- คุยกับ Gemini โดยใช้ประวัติของรอบนั้น สูงสุด 8 ข้อความผู้ใช้ต่อรอบ
- สรุปความกังวล 1–3 เรื่องตามบทสนทนา และแก้ไขสรุปเอง
- สร้างแผนเล็ก ๆ 3 ตัวเลือกตามเรื่องที่เลือก หรือเขียนแผนเอง
- เก็บเฉพาะสรุป/สรุปพร้อมแผนในหน่วยความจำหน้านี้ อัปเดตสถานะ จดความคืบหน้า เปิดดูและลบ
- เริ่มรอบใหม่ จบโดยไม่บันทึก และลองส่งข้อความเดิมใหม่เมื่อเกิดข้อผิดพลาด
- รหัสผู้ทดลองได้ 1–10 รหัส พร้อมรับทราบเงื่อนไขก่อนใช้

แชต สรุป และบันทึกทั้งหมดในแอปหายเมื่อรีเฟรช/ปิดหน้า ไม่มีการแจ้งเตือนจริง ไม่มีบัญชีผู้ใช้ และไม่แชร์บันทึกข้ามอุปกรณ์ รหัสแต่ละชุดเป็นสิทธิ์เข้าใช้แบบทดลอง ไม่ใช่ระบบยืนยันตัวบุคคล

## เริ่มบนเครื่อง

ใช้ Node.js 22.13 ขึ้นไปในสาย 22 หรือ Node.js 24 ขึ้นไป:

```sh
cd classroom
cp .env.example .env
```

กรอกค่าตาม [คู่มือตั้งค่า](SETUP.md) แล้ว:

```sh
npm run dev
```

เปิด `http://127.0.0.1:5173` ไม่ต้องติดตั้งแพ็กเกจเพื่อรันแอปจริง ฟอนต์และ Tailwind ใช้ CDN จึงต้องต่ออินเทอร์เน็ต

หากยังไม่ตั้งค่า แอปแสดง “ห้องทดลองยังไม่เปิด” และปิดปุ่มเริ่มคุย จะไม่แอบใช้คำตอบสำเร็จรูปแทน AI

## ตรวจสอบ

```sh
npm ci
npm run check
npm test
npm run build
```

`jsdom` เป็น dependency สำหรับทดสอบ DOM เท่านั้น การทดสอบไม่ส่งข้อความไป Google และไม่ใช้คีย์จริง

## ฟรีอย่างไร และข้อจำกัด

เลือกโครงการ Gemini ที่เป็น **Free Tier และไม่มี Cloud Billing ที่เปิดใช้งาน** พร้อม Vercel Hobby สำหรับโปรเจกต์ส่วนบุคคลไม่ใช่เชิงพาณิชย์ ไม่ซื้อโดเมน ไม่เปิด paid tier ไม่เปิด auto top-up

- โมเดลเริ่มต้นคือ `gemini-3.5-flash-lite` ซึ่งมีโควตาฟรีตามหน้าราคาเมื่อวันที่ 6 ต.ค. 2026 ต้องตรวจโควตาที่บัญชีจริงอีกครั้งก่อนเปิดทดลอง
- เมื่อ Google ตอบ 429 แอปแจ้งให้รอ ไม่มีการสลับไปบริการเสียเงินหรือ retry อัตโนมัติ
- `GEMINI_FREE_TIER_CONFIRMED=true` เป็นการยืนยันของผู้จัด **ไม่ใช่การตรวจสถานะ billing ผ่าน API** หากใส่คีย์จากโครงการที่เปิด billing แล้ว โค้ดไม่สามารถรับประกันว่าไม่มีค่าใช้จ่าย
- โควตาฟรีอาจไม่พอให้ทั้ง 10 คนทดลองพร้อมกัน แนะนำแบ่งทดลองทีละ 2–3 คนและคุยสั้น ๆ ก่อน
- จำกัดคร่าว ๆ ฝั่งเซิร์ฟเวอร์: 1 คำขอพร้อมกันต่อรหัส เว้น 3 วินาที สูงสุด 15 คำขอต่อรหัส/วัน และรวม 100 คำขอ/วัน **ต่อ server instance** รวมคำขอที่ล้มเหลวหลังเริ่มเรียก AI
- ตัวนับอยู่ในหน่วยความจำ รีเซ็ตเมื่อ instance เริ่มใหม่ และไม่แชร์ระหว่างหลาย instance ของ Vercel จึงเป็นเพียงการลดการกดถี่ ไม่ใช่เพดานโควตารวมที่รับประกันได้ โควตา Google ของโครงการ Free Tier เป็นข้อจำกัดจริง
- เลือกเก็บข้อความผู้ใช้สูงสุด 1,200 ตัวอักษร ประวัติรวมสูงสุด 14,000 ตัวอักษร จำกัดเวลาเรียก AI 25 วินาที

## ความเป็นส่วนตัว

เหมาะสำหรับผู้ใช้ 18 ปีขึ้นไปทดสอบด้วย **เรื่องสมมติ** เท่านั้น ข้อความและประวัติรอบปัจจุบันจะส่งให้ Google Gemini ทุกครั้งที่คุย/สรุป/สร้างแผน บริการฟรีอาจนำไปปรับปรุงผลิตภัณฑ์และอาจมีผู้ตรวจอ่าน ไม่ควรกรอกชื่อจริง ข้อมูลอ่อนไหว หรือความลับ

แอปไม่เขียนบทสนทนาหรือคีย์ลง server log และไม่มีฐานข้อมูลฝั่งเรา แต่ผู้ให้บริการโฮสต์อาจเก็บข้อมูลการร้องขอทั่วไป การกดไม่บันทึกหรือลบในแอป **ไม่ใช่** การลบข้อมูลที่ส่งให้ Google ไปแล้ว แอปช่วยจัดความคิด ไม่ใช่บริการรักษาหรือวินิจฉัย

## โครงสร้าง

- `index.html`, `src/`: หน้าจอและการโต้ตอบ
- `api/ai.js`: ตรวจรหัส/ขนาดข้อมูล/โควตาคร่าว ๆ เรียก Gemini และตรวจคำตอบ
- `server.cjs`: เซิร์ฟเวอร์ในเครื่อง เสิร์ฟเฉพาะไฟล์สาธารณะที่อนุญาต ไม่เสิร์ฟ `.env` หรือโค้ดเซิร์ฟเวอร์
- `scripts/build.cjs`: คัดลอกเฉพาะหน้าเว็บและ `src/` ไป `dist/`
- `vercel.json`: ตั้งค่า Vercel แบบ static frontend + Node function
- `.env.example`: ตัวอย่างชื่อค่าตั้งค่า ไม่มีคีย์หรือรหัสจริง
